# Bangla LLM Hallucination Detection

A Machine Learning project focused on detecting hallucinated responses generated by Bangla Large Language Models (LLMs).

### Project Overview
The system classifies AI-generated Bangla answers into two categories:
- **Faithful (0):** Answers supported by the reference context.
- **Hallucinated (1):** Answers containing false or unsupported information.

### Technologies Used
- R Programming
- Natural Language Processing (NLP)
- Bag of Words (BoW)
- TF-IDF
- Naïve Bayes
- Logistic Regression

### Methodology
- Dataset preparation and exploration using BanglaRQA.
- Bangla text cleaning and Unicode normalization.
- 80:20 train-test split.
- Feature extraction using BoW and TF-IDF.
- Model training with 5-fold cross-validation.
- Evaluation using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
